# Full-Stack Mastery Roadmap

A single-page visual curriculum from HTML/CSS fundamentals through React, Vue, Angular, Node, Python, Go, DevOps, and production systems.

Open `frontend-backend-mastery-roadmap.html` in a browser. No build step.

## What's inside

- **Frontend** — HTML, CSS, JS, TypeScript, Bootstrap, Tailwind, React, Next.js, Vue, Nuxt, Angular, Three.js, Electron
- **Backend** — Node, Express, MongoDB, PostgreSQL, Redis, auth, security, queues, WebSockets, GraphQL
- **Also** — Python, Django, Flask, FastAPI, Go
- **Engineering** — testing, architecture, Docker, cloud, microservices, AI, system design
- **300+** project milestones with progressive difficulty

## How to use

1. Work top → bottom (or jump via the sidebar).
2. **Build → Rebuild → Improve → Combine → Ship.**
3. Treat early projects as drafts; rebuild them with better architecture as you learn.
4. Use the sidebar search to jump to a topic.
